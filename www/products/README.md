# Drop-in product photos (optional)

The app ships with brand-accurate vector art for every product, so it looks
good with no setup. If you'd rather show **real product photos**, just save an
image here named by the product's id — no code changes needed:

| id | product                | file to add   |
|----|------------------------|---------------|
| 1  | Coca-Cola Zero Sugar   | `1.jpg`       |
| 2  | Red Bull Sugarfree     | `2.jpg`       |
| 3  | Red Bull Energy        | `3.jpg`       |
| 4  | Vedica Sparkling Water | `4.jpg`       |
| 5  | Diet Coke              | `5.jpg`       |
| 6  | Schweppes Tonic Water  | `6.jpg`       |

Use a square-ish image with a white/transparent background for the best look.
If a file is missing, the app automatically falls back to the vector art, so
nothing ever shows up broken.
